# MAX Messenger

Веб-приложение для обмена текстовыми сообщениями через GREEN-API. Проект разработан на React и TypeScript в рамках тестового задания на позицию Frontend Developer (React).

## Возможности

- Подключение к GREEN-API с помощью `idInstance` и `apiTokenInstance`.
- Проверка авторизации инстанса через `getStateInstance`.
- Создание чата по номеру телефона через `checkAccount`.
- Отправка текстовых сообщений через `sendMessage`.
- Получение входящих уведомлений через `receiveNotification`.
- Подтверждение обработки уведомлений через `deleteNotification`.
- Отображение входящих и исходящих сообщений.
- Сохранение сессии авторизации, активного чата и истории сообщений в LocalStorage (данные не слетают при перезагрузке страницы).
- Обработка ошибок API и состояний загрузки.
- Адаптивный интерфейс на Tailwind CSS.

## Установка и запуск

### 1. Получение проекта

Если проект уже находится на компьютере, перейдите в его корневую директорию:

```bash
cd D:\workZone\max-messenger
```

Замените путь на фактический путь к папке проекта на вашем компьютере.

Файлы запуска должны находиться в корне проекта рядом с `package.json`:

```text
max-messenger/
├── start-windows.bat
├── start-linux.sh
├── package.json
├── package-lock.json
├── index.html
├── src/
└── ...
```

### 2. Запуск в Windows

**Самый простой способ — запустить приложение через BAT-файл.**

1. Откройте папку проекта.
2. Дважды нажмите на `start-windows.bat`.
3. Дождитесь установки зависимостей, если они ещё не установлены.
4. Дождитесь запуска Vite и появления локального адреса в терминале.
5. Откройте указанный адрес в браузере. Обычно это `http://localhost:5173`.

BAT-файл автоматически:

- Проверяет наличие Node.js и npm.
- Проверяет наличие `package.json`.
- Устанавливает зависимости командой `npm install`, если папка `node_modules` отсутствует.
- Запускает приложение командой `npm run dev`.
- Оставляет окно открытым, чтобы вы могли увидеть возможные ошибки.

Если BAT-файл не запускается, убедитесь, что Node.js установлен и доступен через PATH.

### 3. Запуск в Linux

Для Linux предусмотрен скрипт `start-linux.sh`.

Откройте терминал в корневой папке проекта и выполните:

```bash
chmod +x start-linux.sh
./start-linux.sh
```

Скрипт автоматически проверяет наличие Node.js, npm и `package.json`, устанавливает зависимости при необходимости и запускает сервер разработки.

После запуска откройте локальный адрес, который Vite выведет в терминале. Обычно это `http://localhost:5173`.

Чтобы остановить сервер, нажмите `Ctrl+C` в терминале.

### 4. Ручной запуск через npm

Если вы предпочитаете запускать приложение вручную или проверять отдельные команды, используйте стандартный способ.

Установка зависимостей:

```bash
npm install
```

Запуск в режиме разработки:

```bash
npm run dev
```

Откройте адрес, который Vite выведет в терминале. Обычно это `http://localhost:5173`.

### 5. Проверка проекта

Проверка TypeScript и сборки:

```bash
npm run build
```

Проверка линтером:

```bash
npm run lint
```

Запуск тестов, если соответствующий скрипт настроен в проекте:

```bash
npm run test
```

## Подключение GREEN-API

Для работы приложения необходимы `idInstance` и `apiTokenInstance`. Они вводятся в форме подключения внутри приложения.

### Шаг 1. Получение и настройка учётных данных

1. Откройте [личный кабинет GREEN-API](https://green-api.com).
2. Создайте или выберите свой инстанс.
3. Найдите его идентификатор `idInstance` и токен `apiTokenInstance`.
4. Подключите WhatsApp согласно инструкции GREEN-API.
5. Убедитесь, что инстанс имеет статус `authorized`.

⚠️ **ВАЖНО: Настройка получения уведомлений через HTTP API**
Для корректной работы входящих сообщений в приложении перейдите в настройки вашего инстанса в личном кабинете и в блоке **«Уведомления»** нажмите **«Изменить»**:
- Обязательно оставьте поле **«Адрес отправки уведомлений (URL)»** **ПУСТЫМ**.
- Переведите в положение **«Да»** следующие переключатели:
  * **«Получать уведомления о входящих сообщениях и файлах»**
  * **«Получать уведомления о сообщениях, отправленных с телефона»**
  * **«Получать уведомления о сообщениях, отправленных с API»**
- Нажмите кнопку **«Сохранить изменения»**.

### Шаг 2. Подключение приложения

1. Запустите MAX Messenger.
2. Введите `idInstance`.
3. Введите `apiTokenInstance`.
4. Нажмите **«Подключить API»**.
5. Приложение выполнит запрос `getStateInstance`.
6. При статусе `authorized` откроется экран чата.

Токен является секретными данными. Не публикуйте его в репозитории, README, скриншотах или сообщениях.

### Шаг 3. Создание чата

1. Введите номер собеседника в международном формате, например `+7XXXXXXXXXX`.
2. Нажмите **«Создать чат»**.
3. Приложение выполнит `checkAccount`.
4. Если аккаунт найден, приложение выберет соответствующий чат.

Проверка номера не гарантирует, что собеседник доступен в данный момент.

### Шаг 4. Отправка сообщения

1. Введите текст в поле сообщения.
2. Нажмите **«Отправить»**.
3. Приложение вызовет `sendMessage`.
4. После успешного ответа отправленное сообщение отобразится в переписке.

### Шаг 5. Получение входящего сообщения

1. Убедитесь, что инстанс настроен согласно требованиям из *Шага 1*.
2. Напишите на подключённый WhatsApp с другого устройства или аккаунта.
3. Приложение получает уведомления через `receiveNotification`.
4. Входящее текстовое сообщение обрабатывается и добавляется в открытый чат.
5. После обработки приложение вызывает `deleteNotification`, чтобы подтвердить получение уведомления.

## Используемые методы GREEN-API

| Метод | Назначение |
| --- | --- |
| `getStateInstance` | Проверка состояния инстанса |
| `checkAccount` | Проверка номера и получение идентификатора чата |
| `sendMessage` | Отправка текстового сообщения |
| `receiveNotification` | Получение входящего уведомления |
| `deleteNotification` | Подтверждение обработки уведомления |

### Архитектура

- `api/api.ts` — единый фасад API, через который компоненты вызывают методы GREEN-API.
- `api/client.ts` — общий HTTP-клиент, обработка ответов и ошибок.
- `services/greenApi/` — отдельная реализация каждого метода GREEN-API.
- `features/connection/` — интерфейс подключения и проверки авторизации.
- `features/chat/` — интерфейс чата, обработка входящих уведомлений и отображение сообщений с сохранением сессии.
- `types/` — типы TypeScript для данных API и сообщений.
- `start-windows.bat` — запуск приложения в Windows.
- `start-linux.sh` — запуск приложения в Linux.

## Обработка ошибок

Приложение должно корректно обрабатывать следующие ситуации:

- Некорректные учётные данные.
- Неавторизованный инстанс.
- Недоступность сети или API.
- Ошибки отправки сообщений.
- Отсутствие найденного аккаунта.
- Некорректный ответ API.

## Ограничения текущей версии

- Для отправки и получения сообщений необходим работающий и авторизованный инстанс GREEN-API.
- Реализована работа с текстовыми сообщениями; другие типы сообщений (картинки, файлы) требуют отдельной обработки.
- История переписки и активный чат кэшируются на стороне клиента с помощью `LocalStorage`. Для долгосрочного хранения между устройствами требуется полноценная серверная база данных.

## Цель проекта

Создать минималистичный веб-мессенджер с использованием React и TypeScript, подключённый к GREEN-API, с отправкой и получением текстовых сообщений через HTTP API и разделением интерфейса, бизнес-логики и сервисов.
